# 🚀 Elevator ESP32 — мини-лифт на двух ESP32

Обучающий мини-лифт (для игрушек) на двух платах ESP32:

- **база** (`src/lift`) — шаговый мотор, калибровка, конечный автомат, защиты;
- **пульт** (`src/remote`) — OLED, пять кнопок с подсветкой, беспроводная связь.

Пульт общается с базой по **ESP-NOW**. База также поддерживает Wi-Fi для
веб-настройки и диагностики; пульт автоматически ищет её радиоканал.

Первое подключение, пароли и ограничения: [веб-настройка сети](docs/WEB_SETUP.md).
Управление процессом калибровки: [калибровка из браузера](docs/WEB_CALIBRATION.md).
Скорости и ускорение с сохранением в памяти: [настройки движения](docs/MOTION_SETTINGS.md).

Планы развития и критерии готовности: [дорожная карта проекта](ROADMAP.md).
В ней описаны аварийная остановка всех моторов, этажные датчики, двери,
звуковые оповещения и веб-настройки. Это планы, а не функции текущей прошивки.

## Сборка и прошивка

Проект собирается PlatformIO. Две прошивки живут в одном дереве и разделяются
окружениями `lift` и `remote`.

```bash
pip install platformio
```

```bash
pio run                              # собрать обе прошивки
pio run -e lift -t upload            # прошить базу
pio run -e remote -t upload          # прошить пульт
pio device monitor -b 115200         # лог
```

Если плат подключено несколько, порт указывается явно:

```bash
pio run -e lift -t upload --upload-port /dev/cu.usbserial-0001
```

Зависимости (`FastAccelStepper`, `Adafruit SSD1306`) PlatformIO ставит сам —
ничего добавлять в IDE вручную не нужно.

Есть третье окружение — `lift_bench`. Это та же прошивка базы плюс несколько
команд для проверки логики без собранной шахты: подстановка калибровки
(`BCAL <шагов>`) и имитация концевика (`BTOP1` / `BTOP0` / `BTOPX`).
Для реального лифта его прошивать не нужно.

## Система координат

Ось направлена вверх, ноль — уровень 1-го этажа.

```
   ┌─── верхний концевик   = fullTravel + TOP_MARGIN_STEPS
   │
   ├─── этаж 3             = fullTravel
   │
   ├─── этаж 2             = fullTravel / 2
   │
   └─── этаж 1             = 0
```

`fullTravel` измеряется при калибровке и хранится в NVS: после перезагрузки
калибровать заново не нужно.

## Состояния автомата

| Состояние | Что происходит |
|---|---|
| `NEED_CALIB` | калибровки нет; UP запускает калибровку |
| `CALIB_HOMING_UP` | едем вверх до концевика |
| `CALIB_MOVING_DOWN` | удержанием DOWN спускаемся, F1 фиксирует низ |
| `NEED_HOMING` | калибровка есть, но позиция кабины неизвестна |
| `HOMING` | едем вверх до концевика, чтобы восстановить позицию |
| `IDLE` | готов принимать вызовы этажей |
| `MOVING` | автоматическая поездка на этаж |
| `MANUAL_MOVE` | движение по удержанию UP/DOWN |
| `ERROR` | движение запрещено; нажатие любого этажа снимает ошибку |

Тик автомата — 20 мс. Защиты проверяются каждый проход `loop()`.

### Почему появился `NEED_HOMING`

Шаговый привод не знает своей позиции после включения. Раньше лифт молча
считал, что стоит на 1-м этаже, и по команде «на 3-й» мог уехать в упор.
Теперь позиция считается достоверной только после касания концевика —
единственной физически известной точки шахты.

Из `NEED_HOMING` кнопка UP запускает хоминг. Если при включении кабина уже
на концевике, хоминг не нужен: позиция определяется сразу.

## Калибровка

1. Нажать **UP** — кабина едет вверх до концевика и останавливается.
2. **Удерживать DOWN** — кабина спускается (ускоренно, множитель в `config.h`).
   Отпустили кнопку — кабина встала.
3. Подвести кабину к нижней точке и нажать **Floor 1** — низ зафиксирован,
   ход измерен, значение сохранено в NVS, лифт переходит в `IDLE`.

Повторная калибровка: удержать кнопку на базе (GPIO 33) не менее 3 секунд.

Если измеренный ход меньше `MIN_TRAVEL_STEPS`, калибровка **отклоняется**
с ошибкой `ERR_TRAVEL_TOO_SHORT`. Раньше в этом случае подставлялось
минимальное значение, и лифт ездил по несуществующим этажам.

## Защиты

| Защита | Поведение |
|---|---|
| Верхний концевик | проверяется каждый проход `loop()`, а не раз в 20 мс |
| Программные пределы | движение за `[0, fullTravel]` c запасом — ошибка |
| Лимит хода в калибровке | страховка на случай неисправного концевика |
| Таймауты | отдельные для поездки, хоминга и спуска в калибровке |
| Удержание кнопки | UP/DOWN — команда удержания: пульт повторяет её каждые 150 мс, база останавливается, если повторы пропали дольше чем на 500 мс |
| Потолок ручного движения | непрерывное ручное движение не длится дольше 30 с |
| Экстренный стоп | `CMD_STOP` работает в любом состоянии |

После экстренного стопа позиция считается недостоверной: резкое торможение
может привести к пропуску шагов, поэтому лифт уходит в `NEED_HOMING`.

Все пороги собраны в [`src/lift/config.h`](src/lift/config.h).

## Протокол ESP-NOW

Канал фиксирован (`ESPNOW_CHANNEL`), у каждого пакета есть сигнатура и версия
протокола — чужой трафик и пакеты старой прошивки отбрасываются.

**MAC базы в прошивку пульта не зашивается.** Пульт шлёт команды
широковещательно, пока не получит первый статус, после чего переключается
на прямую адресацию. База так же запоминает адрес пульта. Если связь пропала
дольше чем на 1,5 с, пульт снова начинает поиск.

### Команды: пульт → база

```
CMD_CALL_FLOOR   CMD_STOP          CMD_CALIB       CMD_CALIB_DOWN_START
CMD_CALIB_DOWN_SAVE                CMD_MANUAL_UP   CMD_MANUAL_DOWN
CMD_MANUAL_STOP  CMD_CLEAR_ERROR   CMD_HOME        CMD_DISCOVER
```

Пульт намеренно не знает логики лифта: он шлёт «кнопку нажали / отпустили»,
а что это значит в текущем состоянии, решает база.

### Статус: база → пульт (каждые 200 мс)

```
state  currentFloor  targetFloor  direction
error  speedPercent  needCalib    uptimeMs
```

## Интерфейс пульта

```
+-------------+---------------+-------------+
| F2 >3       |               |     ▲       |
| MOVING      |      2        |   бегущий   |
| 68%         |   (size=3)    |   сегмент   |
+-------------+---------------+-------------+
```

Перерисовка — раз в 150 мс, I2C на 400 кГц. Раньше экран обновлялся каждые
20 мс, и полная перерисовка успевала «съесть» опрос кнопок.

Подсветка кнопок:

| Ситуация | Индикация |
|---|---|
| Нет связи | все мигают часто |
| Ошибка | мигают три этажа; нажатие любого снимает ошибку |
| Нужна калибровка / хоминг | мигает UP |
| Калибровка, спуск | DOWN горит, мигает F1 |
| Стоим на этаже | мигает кнопка этого этажа |
| Едем | ровно горит кнопка целевого этажа |

## Отладка через Serial

База принимает текстовые команды на 115200 — вторая плата для проверки
не нужна:

```
F1 F2 F3   ехать на этаж          STOP    экстренный стоп
UP DOWN    импульс удержания      MSTOP   остановить ручное движение
HOME       хоминг                 CALIB   начать калибровку
CDOWN      калибровка: вниз       CSAVE   калибровка: зафиксировать низ
RESET      стереть калибровку     CLEAR   сбросить ошибку
STATUS     состояние              HELP    справка
```

Уровень логов задаётся флагом `-DLOG_LEVEL` в `platformio.ini`
(0 — тишина, 3 — подробно).

## Схема соединений

```
                      ┌──────────────────────────────┐
                      │          ESP32 БАЗА          │
                      │                              │
                      │   GPIO33 ◄──── Кнопка сброса калибровки (удержание 3 с)
                      │   GPIO32 ◄──── Верхний концевик (NO → GND)
                      │   GPIO34 ◄──── Потенциометр (средний вывод)
                      │                              │
                      │   GPIO18 ─────► STEP         │
                      │   GPIO19 ─────► DIR          │
                      │   GPIO21 ─────► ENABLE       │
                      └──────────┬───────────────────┘
                                 │
                     ┌───────────┴───────────────────────────┐
                     │      Драйвер A4988 / DRV8825          │
                     │   VMOT ◄──── 12 В (3S Li-ion + BMS)   │
                     │   GND  ◄──── общий с ESP32            │
                     │   VDD  ◄──── 3,3–5 В (логика)         │
                     │   1A/1B/2A/2B ──── шаговый мотор      │
                     └───────────────────────────────────────┘

                      ┌──────────────────────────────┐
                      │         ESP32 ПУЛЬТ          │
                      │   GPIO21 ─────► OLED SDA     │
                      │   GPIO22 ─────► OLED SCL     │
                      │                              │
                      │   GPIO13 ◄──── кнопка Down   │
                      │   GPIO14 ◄──── кнопка Up     │
                      │   GPIO27 ◄──── кнопка Floor1 │
                      │   GPIO26 ◄──── кнопка Floor2 │
                      │   GPIO32 ◄──── кнопка Floor3 │
                      │                              │
                      │   GPIO19 ─────► LED Down     │
                      │   GPIO18 ─────► LED Up       │
                      │   GPIO5  ─────► LED F1       │
                      │   GPIO4  ─────► LED F2       │
                      │   GPIO33 ─────► LED F3       │
                      └──────────────────────────────┘
```

Питание пульта: 1S Li-ion → TP4056 → LDO 3,3 В (AMS1117 и подобные).

## Диагностика

| Симптом | Причина |
|---|---|
| Пульт пишет `NO LINK` | база выключена или на другом канале; проверьте `ESPNOW_CHANNEL` в `protocol.h` — он должен совпадать |
| `NEED HOM` после включения | нормальное поведение: нажмите UP, лифт найдёт концевик |
| `ERR 2` (`ERR_TOP_LIMIT`) | концевик сработал там, где не ожидалось — сбилась калибровка |
| `ERR 4` (`ERR_TRAVEL_TOO_SHORT`) | низ зафиксирован слишком близко к концевику |
| Экран не инициализируется | адрес I2C отличается от `0x3C` (см. `src/remote/config.h`) |
