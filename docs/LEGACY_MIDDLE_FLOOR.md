# Временная точка второго этажа

Только текущая прошивка `firmware_v2`, трёхэтажный режим по шагам.

1. Выполнить обычную калибровку верха и низа. После перезагрузки, если ход уже
   сохранён, сначала восстановить позицию по верхнему концевику.
2. Кнопками ↑/↓ пульта подвести кабину к уровню второго этажа и отпустить кнопку.
3. Дождаться полной остановки и состояния «Ожидание», позиция должна быть известна.
4. В вебе под калибровкой нажать «Сохранить здесь второй этаж» и дождаться
   сообщения «Точка второго этажа сохранена».
5. Проверить поездку на второй этаж с пульта под наблюдением. При проскальзывании
   точка по шагам может расходиться с физической; это не замена этажным датчикам.

«Вернуть середину хода» удаляет только ручную точку. Повторная калибровка
низа/верха и полный сброс калибровки удаляют её автоматически, даже если новый
ход совпал со старым. Первый этаж остаётся 0, третий — полный ход.
Сохранение настройки не запускает мотор и не снимает удерживающий момент.

HTTP POST `/api/middle`: action=save|reset, revision и position из свежего
`/api/status`, Basic Auth и X-Lift-Token. HTTP 202 означает очередь, а не запись.
Результат и новая floorRevision подтверждают завершение. Основной цикл повторно
проверяет покой, достоверность позиции, режим обслуживания, возраст запроса,
ревизию геометрии и неизменность позиции. Запись запрещена в пределах допуска
POSITION_TOLERANCE около первого/третьего этажей.

Геометрия v2 хранится одним blob `lift/geometry`: версия, ход, ручной второй этаж.
Старая v1 калибровка читается при отсутствии нового ключа; повреждённая v2 не
заменяется устаревшей v1. При ошибке записи рабочие значения остаются прежними.
Откат на старую прошивку не поддерживает этот формат: перед поездками после
такого отката заново калибровать, старые v1 ключи могут содержать прежний ход.

`LEGACY_MIDDLE_ENABLED` — единая точка отключения временной функции: она управляет
применением ручной точки, доступностью API и отображением блока веба. Сейчас true.
При реализации датчиков выключить и заменить режимом этажных меток; автоматическое
переключение по подключению датчика пока не реализовано.

Проверено автоматически: миграция v1, сохранение/перезагрузка, сброс, границы,
изменение позиции, устаревший запрос/ревизия, отказ NVS, повреждённый blob;
веб-блокировки, подтверждение записи, ошибка памяти и перезапуск базы.
Проверка точности на физическом втором этаже требует ручного совмещения кабины.
