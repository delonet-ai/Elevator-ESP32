# Веб-интерфейс: готовность и оставшиеся работы

Актуально на 10 октября 2026. Этот документ описывает исходники `firmware_v2`;
на физическом лифте пока старая архитектура. Успешная сборка и автотесты
не означают, что новая версия уже прошита или проверена с мотором.

## Реализовано

| Возможность | Где искать |
|---|---|
| Первичная точка доступа, выбор домашней Wi-Fi-сети, сохранение реквизитов | [Настройка сети](WEB_SETUP.md) |
| Веб по IP, авторизация, защита команд токеном | Настройка сети |
| Состояние, позиция, концевик, ошибки с названиями, радиоканал, память | Раздел «Состояние» |
| Свежесть пакетов пульта, служебные пакеты в покое | [Диагностика связи](REMOTE_DIAGNOSTICS.md) |
| Калибровка: верх, спуск с удержанием, сохранение низа, сброс | [Веб-калибровка](WEB_CALIBRATION.md) |
| Восстановление позиции по верху после перезапуска; сброс ошибки | Раздел «Состояние» |
| Программный STOP в закреплённой панели | Доступен при прокрутке |
| Минимум/максимум крутилки 50–10000 шагов/с, отдельные скорости и ускорение | [Параметры движения](MOTION_SETTINGS.md) |
| Сохранение параметров в NVS, проверка ревизий и ошибок записи | Параметры движения |
| Экспорт JSON, загрузка в форму с отдельным сохранением | Параметры движения |
| Последние 32 события, просмотр и экспорт | [Журнал](EVENT_JOURNAL.md) |
| Навигация по разделам и компактная раскладка для телефона | Основная страница |

Управление дверями, фотореверсом, этажными метками и звуком не выдаётся за
работающую функцию: этих подсистем в новой прошивке ещё нет. В локальных
старых исходниках код дверей/фотореверса также не найден. Для их будущего
переноса сначала нужен подтверждённый исходник либо новая реализация.

## Что осталось по веб

- [ ] Проверить страницу на реальных платах и телефоне: сеть, задержки команд,
  уход со страницы, STOP, несколько вкладок, восстановление после обрыва.
- [ ] Проверить расширенный профиль крутилки, сохранение и восстановление позиции
  с мотором. Программный максимум 10000 шагов/с не является гарантией механики.
- [ ] Определить рабочий веб-режим без роутера. Сейчас точка доступа предназначена
  для настройки сети и блокирует движение, а не заменяет обычную панель управления.
- [ ] Добавить вызов этажей из веб отдельным этапом с условиями допуска и
  защитой от повторного запуска. Сейчас поездки доступны с пульта/USB.
- [ ] Настройки количества/высот этажей и датчиков — вместе с этажными метками.
- [ ] Состояние и параметры дверей/фотореверса — вместе с реализацией дверей.
- [ ] Настройки звука — вместе со звуковой подсистемой.
- [ ] Полный экспорт/импорт конфигурации и миграции будущих схем. Сейчас
  резервная копия охватывает только профиль движения.

Прошивка контроллеров, переназначение GPIO33 и аппаратное отключение моторов
не выполняются автоматически как часть разработки веб-интерфейса.
